What's new in 2026.1

Here you'll find the latest features and enhancements in Tricentis Vera 2026.1 . For a detailed list of resolved issues and known issues, check out the technical release notes .

Workflows

We've made workflows more flexible and easier to manage:

  • A new Default Workflow for qTest Requirements, qTest Defects, and Jira Issues.

  • Assign workflows at the Records Management Policy or Record Type level , with safe state mapping when you change workflows on existing records.

  • Full visibility into state changes with Workflow State Mapping Results .

  • A new Available Triggers dropdown on Record Detail for Domain Administrators to move records to the next state.

  • Site Administrators can now create, clone, edit, and delete workflows directly from the Web Portal.

Assign Named Approvers

We've added the ability to assign approval tasks to specific individuals instead of groups:

  • Enforce named assignment globally, per route template, or per approval task level.

  • Tasks appear only in the assignee's approval queue . Notifications go only to the assignee.

  • Automatic reassignment when records are re-routed after revision or rejection.

Consider disabling group approval task emails when Named Approvers are in use.

Approve qTest requirements and defects

Vera now supports routing qTest requirements and defects for approval, with full status transitions, record controls, and approval routes.

Jira integration enhancements

We've improved the Jira integration with the following updates:

  • Choose which Jira Cloud projects display the Vera panel.

  • The Vera panel now links to the Vera record for approval task assignment.

  • Align Vera workflows with Jira to support multiple approval events through an issue's lifecycle.

Notification updates

We've added new notification options to keep you informed:

  • New status mismatch notifications alert Site Administrators when Vera and the source system fall out of sync after a final approval.

  • A new Disable Group Notifications option reduces inbox clutter when Named Approvers are in use.

Upgrade to Tricentis Vera 2026.1

For detailed information on how to upgrade, see Upgrade to 2026.1 .
