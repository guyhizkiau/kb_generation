Configure a security policy

Updated May 20, 2026 Live article

SpecterX security policies define how recipients can access, verify, download, and forward files you share with them. Every file in SpecterX is governed by a policy. This article shows you how to create a new policy and configure its three main sections: Policy Configuration, Access Control, and Data Protection.

Before you get started

  • Permissions required. Administrator role. Only Administrators can create, edit, or delete policies.
  • Default policy. Every SpecterX tenant ships with a Default policy. You cannot delete it, but you can duplicate and modify it.
  • Policy changes take effect immediately. Updating a policy affects all files currently governed by it, including files that have already been shared.
  • Limitations. Rights Management (RMS) encryption supports .pdf, .docx, .xlsx, and .pptx files only. See RMS requirements & limitations.

Open the Policies page

1

In the left navigation, click Policies. The Policies page opens at /policy-editor. The left panel lists all existing policies alphabetically. The right panel shows the editor for the currently selected policy.

Create a new policy

1

At the top of the policy list, click + Add Policy. A new untitled policy appears in the list and is immediately selected. The editor shows all settings at their defaults.

Tip: To start from an existing policy, select it and click Duplicate. The duplicate is created with a (1) suffix.
2

Type a descriptive name for your policy — for example HIPAA — PHI Restricted or Partner NDA — View Only.

Configure Policy Configuration

The Policy Configuration section controls who in your organisation can apply this policy when sharing files.

1

Click Policy Configuration to expand the section (it is expanded by default).

2

If you want only specific users to apply this policy, enable Restrict Policy to Specific Users and select the users or groups from the picker. Leave this off to make the policy available to all Collaborators and Administrators.

Configure Access Control

Recipient Sharing Permissions

1

Under Recipient Sharing Permissions, choose how recipients may forward or reshare your files:

  • Allow Sharing with Anyone — recipients can forward the link to any email address.
  • Restrict Sharing to Recipient's Domain — recipients can only forward within their own domain.
  • Disable Further Sharing — recipients cannot forward the file at all. Recommended for highly sensitive documents.

Verification Requirements

1

Under Verification Requirements, enable one or more verification methods:

  • Email verification — a one-time code is sent to the recipient's email. Most common method for external sharing.
  • Phone (SMS/call) verification — a one-time code is sent by SMS or call to a number you specify at share time.
  • Verify personal secret — the sender defines a password; the recipient must enter it before accessing the file.
Note: You can combine verification methods for multi-factor access.

Allowing Access

1

Enable Acknowledge receipt if you want recipients to confirm they are the intended recipient before the file opens.

Configure Data Protection

The Data Protection section controls how files are protected both in the SpecterX cloud and when downloaded.

Cloud Applications

Protect and Track is always enabled. All access through the SpecterX Viewer is logged in the audit trail.

Downloading files

1

Enable Block file download to hide the download button entirely. Recipients can view the file online but cannot download a copy.

2

Enable Encrypt using a Password to require a sender-defined password on downloaded copies. Supported formats: .pdf, .docx, .xlsx, .pptx. See Password encryption — supported formats.

Note: Block file download and Encrypt using a Password are mutually exclusive.
3

Enable Encrypt using Information Rights Management (RMS) to apply Microsoft RMS encryption to downloaded copies. RMS requires an active Azure RMS or Entra ID configuration. See RMS requirements & limitations.

4

Enable Watermark to add a dynamic watermark showing the recipient's email address and access timestamp in the SpecterX Viewer. See Watermarking — supported formats & limitations.

Set the Recipient Experience language

1

Click Recipient Experience to expand the section. Select the language (English or Hebrew) in which verification prompts are displayed to recipients. For a mixed audience, create one policy per language.

Save and apply the policy

1

After configuring all sections, click Apply at the bottom of the editor. The policy is saved and becomes available in the policy dropdown when sharing files.

Note: Apply is disabled until you make at least one change from the last saved state.
2

To delete a policy, select it and click Delete. You cannot delete the Default policy.

Warning: Deleting a policy does not revoke access to previously shared files — those files fall back to the Default policy.

Policy examples

Use caseRecommended settings
Standard internal shareAllow Sharing with Anyone · Email verification · Protect and Track · Download allowed
External partner NDA fileRestrict to Recipient's Domain · Email verification · Watermark · Block download
Highly sensitive / regulated dataDisable Further Sharing · Phone verification · Watermark · RMS encryption · Block download
Board packageRestrict Policy to Specific Users · Disable Further Sharing · Email + Phone MFA · RMS
