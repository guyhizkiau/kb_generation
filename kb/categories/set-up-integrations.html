⚙️ Set up integrations

Connect SpecterX to your identity provider, cloud storage, DLP tools, and mail protection service.

Identity integration
  • 📄
    Set up Entra ID authentication
    Configure Microsoft Entra ID (formerly Azure AD) as the identity provider for your SpecterX organisation.
    Planned
  • 📄
    Set up Okta authentication
    Configure Okta as the identity provider for your SpecterX organisation using SAML or SCIM.
    Planned
  • 📄
    Set up Google Cloud Identity
    Configure Google Cloud Identity as the identity provider for your SpecterX organisation.
    Planned
Storage integration
  • 📄
    Connect Amazon S3 storage
    Link an AWS S3 bucket as the primary or secondary storage back-end for your SpecterX organisation.
    Planned
  • 📄
    Connect SharePoint storage
    Configure a SharePoint site as the dedicated storage back-end for your SpecterX organisation.
    Planned
  • 📄
    Connect Google Cloud Storage
    Link a Google Cloud Storage bucket as the storage back-end for your SpecterX organisation.
    Planned
Security & classification integration
  • 📄
    Configure DLP mailflow integration
    Integrate SpecterX with your email DLP solution to intercept and protect outbound email automatically.
    Planned
  • 📄
    Configure DLP WebUI integration
    Connect SpecterX to a DLP solution for classification and policy enforcement on files shared from the web platform.
    Planned
  • 📄
    Configure Opswat CDR integration
    Set up Opswat Content Disarm and Reconstruction (CDR) to sanitise files before they are stored in SpecterX.
    Planned
  • 📄
    Configure Microsoft Purview classification
    Connect Microsoft Purview to SpecterX so that Purview sensitivity labels automatically map to SpecterX policies.
    Planned
Mail Protection service
  • 📄
    Set up Mail Protection for Exchange Online
    Configure the SpecterX Mail Protection Service to intercept and protect outbound email from Exchange Online.
    Planned
  • 📄
    Set up Mail Protection for Google Workspace
    Configure the SpecterX Mail Protection Service to intercept and protect outbound email from Google Workspace.
    Planned
  • 📄
    Set up Mail Protection for Cisco SEG
    Configure the SpecterX Mail Protection Service to intercept and protect outbound email from a Cisco Secure Email Gateway.
    Planned
