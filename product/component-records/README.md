# Component records

Internal product-record documents (PRDs, specs, customer-facing overviews) organized by platform area. One folder per SpecterX component or project.

| Subfolder | Contents |
|-----------|----------|
| `admin-platform/` | Audit logs, governance rules, user & groups, SSO, dashboards |
| `connectors/` | Outlook, Gmail, Google Drive, SharePoint, Slack, Salesforce, API |
| `platform-integrations/` | Identity, storage, DLP, CDR, Purview, mail protection |
| `policy-controls/` | Watermarking, password protection, AIP, recipient experience |
| `user-facing-core/` | Folders, workspaces, notifications, send-file-back / request files |

Canonical component names live in [`../product/COMPONENT_TAXONOMY.md`](../product/COMPONENT_TAXONOMY.md).
