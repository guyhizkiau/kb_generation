# Legacy manuals

Historical SpecterX customer and operator documentation (`.docx`), imported from Google Drive. These are **source material** for the new KB pipeline — not the published help center.

| Subfolder | Contents |
|-----------|----------|
| `customer/` | End-user manuals, integration guides, per-tenant variants |
| `operator/` | Tenant setup, gateway deployment, on-prem integrator guides |
| `policy-control-guides/` | Admin onboarding and policy configuration drafts |
| `mailflow-and-workspaces/` | Mailflow integration and workspaces operator docs |
| `misc/` | Standalone capability and connector documents at import root |

The editorial plan for the new KB is in [`../editorial/ARTICLES_PLAN.md`](../editorial/ARTICLES_PLAN.md).
